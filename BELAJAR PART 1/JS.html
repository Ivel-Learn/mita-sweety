JAVASCRIPT

JavaScript adalah bahasa pemrograman yang digunakan untuk membuat halaman web menjadi interaktif. Berbedadengan HTML (struktur) dan CSS (tampilan), JavaScript memberikan fungsionalitas danlogika, seperti menanganitombol diklik, membuat animasi, memvalidasi formulir, dan berkomunikasi dengan server tanpa memuat ulang halaman(AJAX).

    Penjelasan Singkat
  • JavaScript bekerja di sisi client (browser), artinya langsung dijalankan di komputer pengguna
  • Bisa digunakan untuk mengontrol elemen HTML dan CSS secara dinamis
    Fungsi JavaScript :
  1. Menambahkan interaksi pada halaman web (misalnya tombol, slideshow, form dinamis).
  2. Mengatur dan mengubah konten HTML/CSS secara real-time
  3. Digunakan dalam pengembangan aplikasi web modern (misalnya dengan framework seperti React, Vue, atau Angular).
  4. Bisa juga digunakan di server-side dengan teknologi seperti Node.js.
