HTML & CSS

HTML

HTML (HyperText Markup Language) adalah bahasa markah standar yang digunakan untuk membuat dan menyusun halaman web. HTML digunakan untuk menentukan struktur dasar dari sebuah halaman web, seperti paragraf, judul, tabel, gambar, tautan, dan elemen-elemen lainnya.

    Penjelasan Singkat
  • Hyper Text :Mengacu pada Text yang memiliki tautan (link) ke halaman lain
  • Markup Language: Merupakan bahasa yang menggunakan tag-tag untuk menandai elemen elemen dalam dokumen.
    Fungsi HTML :
  1. Menyusun Konten Halaman Web
  2. Menandai Elemen-Elemen seperti Teks, gambar, video, dll
  3. Membantu Browser memahami bagaimana menampilkan halaman tersebut





















CSS

CSS (Cascading Style Sheets) adalah bahasa yang digunakan untuk mengatur tampilan dan desain dari elemen-elemen yang ditulis dalam HTML. Jadi, kalau HTML itu struktur, maka CSS adalah gaya atau tampilanseperti warna, ukuran, jenis huruf, tata letak, dan animas.

    Penjelasan Singkat
  • Cascading :Artinya "bertingkat" — karena gaya yang diterapkan bisa berasal dari beberapa sumber dan akan mengikuti urutan prioritas (misalnya dari CSS internal, eksternal, atau inline).
  • Style Sheets: Lembar yang berisi aturan-aturan gaya.
    Fungsi CSS :
  1. Mengatur warna, ukuran, dan posisi elemen web.
  2. Membuat desain yang konsisten di seluruh halaman.
  3. Memisahkan antara konten (HTML) dan tampilan (CSS), supaya lebih rapi dan mudah diatur.
